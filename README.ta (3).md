நான் **AI அமைப்புகளில் கவனம் செலுத்தும் மென்பொருள் பொறியாளர்**. AI மாதிரிகளை (models) பயன்படுத்தக்கூடிய தயாரிப்புகளாக மாற்றும் பொறியியலை நான் உருவாக்குகிறேன்: LLM அடிப்படையிலான சேவைகள், retrieval pipelines, agent கருவிகள், மேலும் production-இல் அவை நம்பகமாக இயங்க உதவும் மதிப்பீடு (evaluation) மற்றும் கண்காணிப்பு (observability). வேகமான, அளவிடக்கூடிய, எளிதாக இயக்கக்கூடிய அமைப்புகளே என் விருப்பம்.

- 🧠 **ஆர்வமுள்ள துறைகள்:** LLM inference & serving, agents / tool use, evals, retrieval, MLOps
- 📊 **மேலும்:** data science & ML சோதனைகள் — [Kaggle](https://www.kaggle.com/jasmine20006778)-இல் பாருங்கள்
- 💬 **என்னிடம் கேளுங்கள்:** Python, backend architecture, ML-ஐ production-க்கு கொண்டு செல்வது
